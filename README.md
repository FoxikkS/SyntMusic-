# SyntMusic

Минималистичный плеер локальной музыки для Android с синхронизированным текстом песен.

Никаких стримингов и аккаунтов: музыка играет с устройства, а главное на экране — обложка, трек и текст.

## Возможности

**Плеер**
- Фон из размытой обложки и цвет интерфейса, подстроенный под обложку
- Свайп обложки влево/вправо — переключение трека, свайп вниз — свернуть плеер
- Мини-плеер со свайпами и прогрессом
- Shuffle, Repeat, очередь, таймер сна с плавным затуханием


**Текст песен**
- Синхронизированный текст (LRC) с подсветкой и автопрокруткой
- Нажатие на строку — перемотка к ней
- Караоке-заливка активной строки и индикатор проигрыша
- При перемотке ползунком видно время и строку текста в этом месте
- Источники текста по порядку:
  1. файл `.lrc` / `.txt` рядом с аудиофайлом;
  2. выбранная папка с текстами;
  3. текст, встроенный в теги (ID3 USLT, MP4 ©lyr, Vorbis LYRICS);
  4. [LRCLIB](https://lrclib.net) — открытая база синхронизированных текстов (можно отключить).

**Звук**
- Эквалайзер с редактируемой кривой, пресетами и усилением басов
- Фоновое воспроизведение, уведомление, управление с экрана блокировки и гарнитуры
- MP3, FLAC, M4A, AAC, OGG, WAV

**Библиотека**
- Песни, альбомы, исполнители, недавно воспроизведённые
- Поиск по названию, исполнителю и альбому


## Сборка

Требуется Android Studio (JDK 17+) и Android SDK 35.

```bash
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/`. 

## Приватность

Приложение не собирает данные. Сетевые запросы — только к LRCLIB за текстами песен
(название, исполнитель, альбом и длительность трека); это отключается в меню плеера.
